# Shah Syed Hussam Ali: portfolio

This is the source of https://engr-hussam-ali.github.io/, the portfolio of a simulation engineer working on finite-element analysis, thermal-structural behaviour and design optimisation.

It has two case studies, both from the KRISS Safety IoT project at Sejong University:

- [Why a tilt sensor reads a tilt that isn't there](https://engr-hussam-ali.github.io/tilt-sensor.html): thermal-structural FEA of an IoT sensor package, 11 verification checks, 19 fixing conditions, and a Kriging layout optimisation that cut the thermal error by 97.8 %.
- [A verified settlement dataset for placing sensors in buildings](https://engr-hussam-ali.github.io/settlement-dataset.html): an automated Abaqus pipeline for 108 buildings and 10,692 analyses, packaged as GNN Studio 1.0.

The site is plain HTML and CSS with no build step. The fonts (Archivo and Source Serif 4, SIL Open Font License) are self-hosted.
