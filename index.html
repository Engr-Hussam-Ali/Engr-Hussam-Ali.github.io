Case studies

Both come from the Safety IoT project of the Korea Research Institute of Standards and Science (KRISS), South Korea's national measurement standards laboratory. The project aims to make low-cost building tilt sensors trustworthy.

Why a tilt sensor reads a tilt that isn't there

A temperature swing makes the housing, screws and circuit boards of a tilt sensor expand by different amounts, and the chip reads the bending as tilt. I modelled the whole package, verified the model with 11 checks, compared 19 ways of fixing it to a wall or floor, found the mechanism behind the error, and optimised the internal screw and stem layout.

Tools
Abaqus/Standard, Python, MATLAB (Kriging)
Scale
19 fixing conditions, 216 load cases, 103 optimisation runs
Outcome
Thermal error cut by 97.8 %; a ranked mounting guide
Read the sensor-package case study

A verified settlement dataset for placing sensors in buildings

Where should a tilt sensor go on a building that may settle unevenly? The answer changes with the building and the settlement pattern, so it has to be learned from many simulations. I built an automated Abaqus pipeline that generates 108 concrete-frame buildings, runs 10,692 settlement analyses, checks every building against eight gates and writes a training dataset.

Tools
Abaqus/Standard, Python 3, Abaqus Python, Windows installer
Scale
108 buildings, 669,971 nodes, 10,692 analyses
Outcome
432-file dataset and the GNN Studio 1.0 program
Read the settlement-dataset case study

How I work

A simulation is only useful if someone can rely on it. These habits came out of the projects above.

Verify before optimising

The sensor model had to pass mesh-convergence and 11 independent checks before it was used for a single design comparison. The settlement pipeline stops a building that fails any of its eight gates.

Find the root cause, not a workaround

Five tie reversions and nine singularities came from one hidden 0.1° tilt of a circuit board, found by reading the solver's pre-processing warnings rather than its summary log.

Keep every number traceable

Reported values are extracted from the result files by script and kept in a register with their source, so any figure in a report can be traced back to the run that produced it.

Say what the model cannot tell you

The sensor model ranks mounting options reliably, but its smallest output is the residual of two large opposite rotations. The report says so, and names the higher-fidelity model needed for absolute values.
